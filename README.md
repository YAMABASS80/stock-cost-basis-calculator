# 米国株取得費計算スクリプト

日本の税法に基づく総平均法で米国株の取得費を計算するPythonスクリプトです。

## 概要

このスクリプトは、米国株の売却時における取得費を日本の税法に準拠した総平均法で計算します。同一銘柄の株式を複数回購入・売却した場合に、各売却タイミングでの取得費を正確に算出できます。

### 主な機能

- CSV形式の取引履歴ファイルの読み込み
- 総平均法による1株あたり取得単価の計算
- 売却時の取得費の自動計算
- **為替レートの自動取得**（Yahoo Finance、exchange_rate が空欄の行のみ）
- CSV形式またはコンソールへの結果出力
- 包括的なエラーハンドリング

## 必要要件

- Python 3.14以上
- uvパッケージマネージャ
- インターネット接続（為替レートの自動取得を利用する場合のみ）

## 入力CSVフォーマット

入力CSVファイルは以下のフィールドを含む必要があります：

| フィールド | 型 | 説明 | 例 |
|-----------|-----|------|-----|
| transaction_date | string | 取引日（YYYYMMDD形式） | 20240115 |
| transaction | string | 取引種別（buy/sell） | buy |
| exchange_rate | string | 為替レート（円/ドル）。**空欄にすると自動取得** | 150.50 |
| unit | string | 株数 | 100 |
| unit_price | string | 1株あたり価格（USD） | 150.25 |

> **注:** `exchange_rate` 列（ヘッダー）は必須ですが、各行の値は空欄にできます。
> 空欄の行は取引日の USD/JPY レートを Yahoo Finance から自動取得します。
> 詳しくは[為替レートの自動取得](#為替レートの自動取得)を参照してください。

### 入力例

```csv
transaction_date,transaction,exchange_rate,unit,unit_price
20240115,buy,150.50,100,150.25
20240220,buy,148.00,50,155.00
20240315,sell,152.00,80,160.00
20240420,buy,149.50,30,158.00
20240515,sell,151.00,50,162.00
```

#### 為替レートを自動取得する入力例

`exchange_rate` を空欄にすると、取引日のレートが自動的に補完されます。
入力済みの値はそのまま使用され、上書きされません。

```csv
transaction_date,transaction,exchange_rate,unit,unit_price
20240115,buy,,100,150.25
20240220,buy,148.00,50,155.00
20240315,sell,,80,160.00
```

## 為替レートの自動取得

`exchange_rate` が空欄の行については、[Yahoo Finance](https://finance.yahoo.com/quote/USDJPY=X/)
の USD/JPY 日足データから取引日のレートを自動取得します。

### 動作仕様

- **空欄の行のみ**自動取得します。値が入力済みの行はその値をそのまま使用します。
- 取引日が**土日・祝日**など市場閉場日の場合は、**直前の営業日**の終値レートを採用します。
- 取得したレートは小数第4位に丸めます（四捨五入）。
- 取得済みのレートはキャッシュし、API呼び出し回数を抑えます。
- 外部ライブラリは不要です（Python標準ライブラリの `urllib` のみを使用）。

### 自動取得を無効にする

ネットワークを使わず、空欄をエラーとして扱いたい場合は `--no-auto-fx` を指定します。

```bash
uv run python main.py input.csv --no-auto-fx
```

> **免責:** 自動取得される為替レートは Yahoo Finance が提供する市場レートです。
> 税務申告で用いるべきレート（例: TTM など）とは異なる場合があります。
> 取得値は参考情報としてご利用いただき、最終的な判断は税理士等の専門家にご確認ください。

## 出力フォーマット

出力には以下の情報が含まれます：

| フィールド | 型 | 説明 |
|-----------|-----|------|
| transaction_date | string | 売却日（YYYY-MM-DD形式） |
| shares_sold | int | 売却株数 |
| average_cost_per_share | int | 1株あたり取得単価（円、1円未満切り上げ） |
| total_cost_basis | int | 取得費合計（円） |

### 出力例

```csv
transaction_date,shares_sold,average_cost_per_share,total_cost_basis
2024-03-15,80,22722,1817760
2024-05-15,50,22992,1149600
```

### 出力例の解釈方法

上記の出力例は、以下のように解釈します：

#### 1行目: 2024-03-15の売却

```
transaction_date: 2024-03-15
shares_sold: 80
average_cost_per_share: 22722
total_cost_basis: 1817760
```

**意味:**
- 2024年3月15日に80株を売却しました
- この時点での1株あたりの取得単価は22,722円です（1円未満切り上げ）
- この売却における取得費の合計は1,817,760円です（22,722円 × 80株）

**税務申告での使い方:**
- 確定申告書の「株式等の譲渡所得」欄に記入する際、この売却の取得費として1,817,760円を使用します
- 売却価額からこの取得費を差し引いた金額が譲渡所得（または損失）となります

#### 2行目: 2024-05-15の売却

```
transaction_date: 2024-05-15
shares_sold: 50
average_cost_per_share: 22992
total_cost_basis: 1149600
```

**意味:**
- 2024年5月15日に50株を売却しました
- この時点での1株あたりの取得単価は22,992円です（1円未満切り上げ）
- この売却における取得費の合計は1,149,600円です（22,992円 × 50株）

**注意点:**
- 1株あたりの取得単価が1行目（22,722円）と2行目（22,992円）で異なっています
- これは、1回目の売却後に追加購入があったため、総平均法により取得単価が再計算されたためです
- 各売却時点での取得単価は、その時点までの全購入取引を基に計算されます

#### 実際の計算例

入力例のデータを使用した場合の計算過程：

**1回目の売却（2024-03-15）まで:**
1. 2024-01-15: 100株を150.25 USD × 150.50円 = 2,262,262.5円で購入
2. 2024-02-20: 50株を155.00 USD × 148.00円 = 1,147,000円で購入
3. 合計: 150株を3,409,262.5円で保有
4. 1株あたり取得単価: 3,409,262.5円 ÷ 150株 = 22,728.416...円 → 22,729円（切り上げ）
5. 2024-03-15: 80株売却 → 取得費 = 22,729円 × 80株 = 1,818,320円

**注:** 実際の出力例では22,722円となっていますが、これは入力データの詳細な値によって変動します。

**2回目の売却（2024-05-15）まで:**
1. 1回目売却後の残株: 70株（取得価額総額は按分計算）
2. 2024-04-20: 30株を158.00 USD × 149.50円 = 708,510円で追加購入
3. 合計: 100株を保有（新しい取得価額総額で再計算）
4. 1株あたり取得単価: 再計算された金額 ÷ 100株 = 22,992円（切り上げ）
5. 2024-05-15: 50株売却 → 取得費 = 22,992円 × 50株 = 1,149,600円

#### 重要なポイント

1. **取得単価は売却ごとに変わる可能性がある**
   - 売却と売却の間に新たな購入があった場合、取得単価は再計算されます
   - 総平均法では、その時点での全保有株の平均取得単価を使用します

2. **1円未満の切り上げ**
   - 日本の税法では、1株あたりの取得単価は1円未満を切り上げます
   - これにより、実際の取得費よりもわずかに高めの金額になります

3. **税務申告での利用**
   - 各売却取引について、`total_cost_basis`の値を確定申告書に記入します
   - 複数回の売却がある場合は、それぞれの取得費を個別に記録します

## 計算方法

### 総平均法

このスクリプトは日本の税法に基づく総平均法を使用します：

1. **1株あたり取得単価の計算**
   ```
   取得単価 = 購入価額の総額 ÷ 購入株数の総数
   ```

2. **円建て購入金額の計算**
   ```
   購入金額（円） = 株価（USD） × 株数 × 為替レート
   ```

3. **取得費の計算**
   ```
   取得費 = 取得単価（1円未満切り上げ） × 売却株数
   ```

### 処理順序

1. 取引を日付順にソート（同日の場合は買い→売りの順）
2. 購入取引ごとに取得価額総額と保有株数を更新
3. 売却取引ごとに取得費を計算し、残株数を更新

## エラーハンドリング

スクリプトは以下のエラーを適切に処理します：

- **FileNotFoundError**: 入力CSVファイルが存在しない
- **ValidationError**: データ形式が不正（日付、取引種別、数値など）
- **CalculationError**: 計算エラー（保有株数を超える売却など）
- **FXFetchError**: 為替レートの自動取得に失敗（ネットワーク障害、該当日のレート欠落など）
- **ArgumentError**: コマンドライン引数のエラー

エラーメッセージは標準エラー出力に出力され、適切な終了コードが返されます。
